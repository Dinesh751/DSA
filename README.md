## 🧠 Master Algorithm Patterns

### 1. Hashing Patterns
```java
// Two Sum Pattern
Map<Integer, Integer> map = new HashMap<>();
for (int i = 0; i < nums.length; i++) {
    int complement = target - nums[i];
    if (map.containsKey(complement)) {
        return new int[]{map.get(complement), i};
    }
    map.put(nums[i], i);
}
```

### 2. Sliding Window Patterns
```java
// Variable Window Template
int left = 0, right = 0;
while (right < array.length) {
    // Expand window
    while (window_condition_violated) {
        // Shrink window
        left++;
    }
    // Update result
    right++;
}
```

### 3. Two Pointers Patterns
```java
// Opposite Direction
int left = 0, right = array.length - 1;
while (left < right) {
    if (condition) {
        // Process and move pointers
    }
    // Move pointers based on condition
}
```

### 4. Stack Patterns
```java
// Monotonic Stack (Next Greater Element)
Stack<Integer> stack = new Stack<>();
for (int i = 0; i < array.length; i++) {
    while (!stack.isEmpty() && array[i] > array[stack.peek()]) {
        int index = stack.pop();
        result[index] = i - index;
    }
    stack.push(i);
}
```

### 5. Binary Search Patterns
```java
// Classic Binary Search
int left = 0, right = array.length - 1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (array[mid] == target) return mid;
    else if (array[mid] < target) left = mid + 1;
    else right = mid - 1;
}
```

### 6. Linked List Patterns
```java
// Floyd's Cycle Detection
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow == fast) return true; // Cycle detected
}
```

### 7. Interval Patterns
```java
// Interval Merging
Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
List<int[]> merged = new ArrayList<>();
for (int[] interval : intervals) {
    if (merged.isEmpty() || merged.get(merged.size()-1)[1] < interval[0]) {
        merged.add(interval);
    } else {
        merged.get(merged.size()-1)[1] = Math.max(merged.get(merged.size()-1)[1], interval[1]);
    }
}
```

## � Complexity Analysis Reference

| Pattern | Time Complexity | Space Complexity | Use Cases |
|---------|----------------|------------------|-----------|
| HashMap Lookup | O(1) avg | O(n) | Two Sum, Anagrams |
| Sliding Window | O(n) | O(1) | Subarray problems |
| Two Pointers | O(n) | O(1) | Palindromes, merging |
| Binary Search | O(log n) | O(1) | Sorted arrays |
| Stack Operations | O(n) | O(n) | Matching, monotonic |
| Linked List Traversal | O(n) | O(1) | List manipulation |
| Floyd's Algorithm | O(n) | O(1) | Cycle detection |
| Interval Sorting | O(n log n) | O(1) | Interval problems |
| Graph Traversal | O(V + E) | O(V) | Path finding |
| Dynamic Programming | O(n²) typical | O(n) or O(1) | Optimization |
